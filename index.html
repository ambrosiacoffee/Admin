Move product images out of the database

Photos uploaded with the Upload Image buttons are stored inside the Firebase database. Every shopper downloads all of them when the store opens, which makes the store slower and uses up the free plan. Moving them to your store's GitHub makes the store faster and keeps the database small.

Checking…
  1. Download the images.
  2. Upload them to the store's GitHub. Unzip the file. In the GitHub repository of ambrosiacoffee.store, press Add file → Upload files and drop in the images folder, then Commit changes. Wait 2–3 minutes.
  3. Switch the store to the GitHub images. Each image is checked first; only images that load correctly are switched, the rest stay as they are.
